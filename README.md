# Código Secreto

A retro-terminal "hacking" puzzle game (Portuguese UI) that teaches algorithms. Each mission gives you an input and an expected output, and you write a small assembly-style program to turn one into the other.

Run: open `index.html` in a browser, or `python3 -m http.server 5179` in this folder and open http://localhost:5179

- Registers `ACC` and `BAK`, labels (`NAME:`) and comments (`#`)
- Run, step, pause and stop, with adjustable speed
- Hints for each mission, plus a cycle and line count to improve your solution

Everything lives in a single `index.html`.
